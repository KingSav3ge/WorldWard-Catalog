# Proposed fictional Rise expansion evaluation

Status: proposed, unselected, unimplemented. The profile is an original fictional example, not universal Rise or historical authority. Values are deliberately authored solely for this proposed demonstration. Existing source, historical archives, fixture IDs, saves and eight family qualification states are unchanged.

The actor instructions describe choices; evaluator-only files contain synthetic setup and expected truth. These cases are design acceptance criteria and have never been executed against the Core. They do not establish outcomes, NPC consent, runtime authority, live-provider quality or release approval. Profiles, permissions, effects, actor-scoped receipts, concurrency and migration need a reviewed Engine contract; App must wait for an explicit compatible selection. No generated scenario automatically seeds a player's save.

The proposed scope includes last-place admission, competing projects, pause/completion, pre-work and post-work cancellation, refusal, offered/accepted expansion, invalid jurisdiction, conservation, exact retry, reload and restore fencing. After-work disposition needs a further reviewed contract. Needs, agency, non-Rise and multi-session actual gameplay remain open; these cases do not close any target gate.

Coordinator validation at the exact candidate: `python -B -m unittest tools.tests.test_proposed_rise_expansion_contract -v`, then `python -B IRGS_Catalog/verify_catalog.py`. These structural checks cannot execute the feature. The published 3.4.8 Engine/App pins are dependencies, not evidence that they implement this proposal.
