## Preview and play boundaries

New entries are Planned public previews with working descriptions, proposed settings, perspectives, scope, featured systems, dependencies and source provenance. The user approved preview integration, not a complete campaign release. Concept Draft is reserved for internal records and excluded from public projection and counts. Current production work is labelled In Development.

The preview source cannot grant a launch. Only the existing Hundred Years' War and Rise discovery records can contribute their current reviewed starts; Kira contributes a read-only world guide. Century's 37 supported dates and bounded fictional openings remain available. Rise's fictional R00 slice remains available while its eight design families are held. No new campaign initializer was added by the catalogue.

The document's older statement that Century alone is playable was reconciled with the user's already authorized and implemented Rise slice. Neither limited slice is advertised as its full completed product. Existing campaign creation still validates the selected entry, source digest, character policy and request identity on the server.

Kira v0.5 was separately, explicitly adopted by the user as working canon. Its lorebook and dossier supersede older creative documents; existing saves retain their actual history. Catalogue copy remains working promotional description, and cannot replace that adopted foundation or select Kieran as the player.

## App behavior

The library provides type, setting, period, genre, launch/future/system and availability filters. Text search includes titles, places, periods, roles, synopses and featured systems. Filters combine, preserve a zero-result state and reset accessibly. All previews and guide searches are read-only and escape supplied text. No remote image is loaded; covers are typographic placeholders.

Before any full concept can release, its project must pass the supplied eight phases: concept approval; historical or fictional foundation; player entry design; shared simulation integration; living-world population; scenario implementation; verification; publication. A requirements list or a passing preview test does not complete those phases.
